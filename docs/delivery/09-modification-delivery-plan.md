# 调皮狗 AI 系统修改与交付方案

## 1. 项目目标

完成系统从阿里云环境向腾讯云的迁移与稳定运行，解决视频生成接口、OSS 上传、运行日志及部署方式等问题，确保系统能够正常生成、保存和播放视频，并具备后续运维和问题追踪能力。

## 2. 当前进度

当前整体完成度约为 **90%**，核心功能已经部署至腾讯云生产环境，并通过实际视频任务验证。

已完成内容：

- 全部切换为服务器本地源码构建，不再依赖失效的 Git 镜像和远程应用镜像。
- 完成腾讯云生产环境部署。
- 完成阿里云数据库数据迁移。
- 修复系统初始化缺少 `arkDefaultGroupId` 的问题。
- 完成 ToAPIs Seedance 2 视频生成接口适配。
- 修复视频任务创建、状态查询和结果地址解析。
- 增加视频生成全过程日志页面。
- 日志支持查看请求参数、执行结果、错误原因和耗时。
- 增加按时间段删除日志功能。
- 修复腾讯云无法访问阿里云 OSS 内网地址的问题。
- OSS 上传切换为公网 HTTPS，实测约 5 秒完成上传。
- 完成真实视频任务验证，视频可以正常生成、上传和播放。
- 后端 28 个测试文件、169 项自动化测试全部通过。

当前生产版本：`prod-20260819-111731`

## 4. 验收标准

- 用户可以正常登录并访问各业务页面。
- 视频任务能够正常提交和查询。
- 视频生成完成后能够上传至 OSS。
- 前端可以正常播放生成结果。
- 日志能够完整记录每一步请求、参数、结果、错误和耗时。
- 日志能够按指定时间范围删除。
- 数据库和 Redis 状态正常。
- 所有生产容器稳定运行，无反复重启和持续错误。
- 旧数据、用户、项目和历史任务能够正常查询。

## 6. 风险与保障

当前主要风险是第三方视频中转接口、阿里云 OSS 或公网网络出现波动。系统已经增加任务重试、详细日志和错误记录，出现异常时可以快速定位。

生产部署保留上一版本。若新版本发生严重异常，可以快速回滚，且不会影响数据库和历史业务数据。
