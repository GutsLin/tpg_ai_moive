# Narrix 测试与验收说明书

| 项目 | 说明 |
| --- | --- |
| 文档编号 | NARRIX-TEST-07 |
| 文档版本 | V1.0 |
| 适用系统 | Narrix 自部署交付版本 |
| 编制依据 | 当前交付源码、测试文件、业务接口和页面功能 |

## 1. 测试范围

测试覆盖以下模块：

- 安装向导。
- 登录与会话。
- 用户管理。
- 项目管理。
- 素材组管理。
- 素材上传与同步。
- 视频任务创建和查询。
- 视频统计。
- 系统配置。
- 部署启动和环境变量。

## 2. 测试类型

| 类型 | 工具 | 说明 |
| --- | --- | --- |
| 后端单元和接口测试 | Vitest、supertest | 验证 service、middleware、routes |
| 前端单元测试 | Vitest、Testing Library | 验证页面和工具函数 |
| 端到端测试 | Playwright | 验证登录、项目、素材、视频等主流程 |
| 类型检查 | TypeScript | 验证类型一致性 |
| 部署检查 | Docker Compose | 验证容器服务可启动 |

## 3. 执行命令

后端：

```bash
cd backend
pnpm exec tsc --noEmit
pnpm test
```

前端：

```bash
cd frontend
pnpm exec tsc --noEmit
pnpm test -- --run
pnpm build
```

端到端：

```bash
cd frontend
pnpm exec playwright install chromium
pnpm test:e2e
```

## 4. 功能测试用例

### 4.1 安装向导

| 编号 | 用例 | 预期结果 |
| --- | --- | --- |
| SETUP-001 | 首次访问系统 | 自动进入安装向导 |
| SETUP-002 | 获取安装状态 | 返回 initialized、environment、health |
| SETUP-003 | 管理员密码少于 8 位 | 前端或后端提示校验失败 |
| SETUP-004 | OSS 配置校验成功 | 返回可继续状态 |
| SETUP-005 | 火山 AK/SK 校验失败 | 返回失败提示，不允许继续 |

## 5. 验收标准

系统交付验收应满足：

1. 前端、后端、数据库、Redis、worker 可正常启动。
2. 安装向导可完成初始化。
3. 管理员可登录并访问所有管理页面。
4. 项目、用户、素材组、素材、视频、配置主流程可用。
5. 项目数据隔离有效。
6. 素材上传和预览使用临时访问地址。
7. 视频任务可提交、查询和展示状态。
8. 关键异常有明确提示。
9. 测试命令可执行，关键用例通过。
10. 部署文档中的命令可在目标环境复现。
