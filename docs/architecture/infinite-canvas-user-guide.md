# 无限画布平台 — 新旧版本功能对比

## 剧集管理

| 你现在怎么做 | 以后怎么做 | 好在哪 |
| --- | --- | --- |
| 每集的素材、生成任务混在一个项目里，靠名字区分第几集 | 每集一个画布，集与集完全隔离 | 第3集的素材不会混到第5集里 |
| 翻看之前某集用了什么参数 → 翻任务列表找 | 打开对应集的画布 → 节点+连线就是完整记录 | 不用翻列表，画布即档案 |
| 一集的多个分镜散落在任务列表 | 一集的画布上按顺序排好所有分镜节点 → 连线表示播放顺序 | 一眼看到整集全貌 |

## 视频生成

| 你现在怎么做 | 以后怎么做 | 好在哪 |
| --- | --- | --- |
| 打开生成页 → 选模型 → 填参数 → 提交 → 等结果 → 看列表 | 画布上放一个节点 → 填提示词 → 生成 → 结果直接在节点里播放 | 不用来回切页面，结果和参数同框 |
| 不满意要重新生成 → 手动重填一遍参数 | 右键复制节点 → 改提示词 → 生成 | 参数自动带过来，不用重填 |
| 想对比两种风格的效果 → 截图或开两个浏览器标签 | 画布上并排放两个节点 → 各自生成 → 一眼对比 | 效果对比不再靠截图 |
| 分镜编排靠 Excel / 飞书 | 画布上按顺序放节点 → 连线表示播放顺序 | 分镜和生成在一个地方完成 |
| 整个探索过程无法保存 | 画布自动保存，下次打开原样还在 | 创意过程不丢失 |

## 素材使用

| 你现在怎么做 | 以后怎么做 | 好在哪 |
| --- | --- | --- |
| 素材在素材页 → 生成在生成页 → 来回切换 | 素材直接拖到画布上 → 连线到生成节点 | 不用切页面，素材和生成结果同框 |
| 选中素材后要在生成表单里手动关联 | 拖入即用，连线即关联 | 操作更直觉 |

## 提示词

| 你现在怎么做 | 以后怎么做 | 好在哪 |
| --- | --- | --- |
| 每次从头写提示词 | 提示词中心搜一条 → 一键填充到节点 → 可改 | 不用每次从零写 |
| 好用的提示词没法保存分享 | 右键节点 → 「保存为提示词」→ 全公司可用 | 好东西大家共享 |
| 不会写提示词时只能自己琢磨 | 问创意助手 → AI 帮你写 → 30 秒出结果 | 不用专业经验也能写出好提示词 |

## 参数配置

| 你现在怎么做 | 以后怎么做 | 好在哪 |
| --- | --- | --- |
| 每次手动选模型、分辨率、时长、比例、音频 | 技能中心选一个技能 → 所有参数一键填好 | 不用记参数怎么搭配 |
| 调好一组参数没法保存复用 | 右键节点 → 「保存为技能」→ 下次一键应用 | 调一次用无数次 |
| 新人不熟悉参数容易配错 | 选对应场景的技能 → 参数自动正确 | 降低出错率 |

## 创意协作

| 你现在怎么做 | 以后怎么做 | 好在哪 |
| --- | --- | --- |
| 评审创意靠截图 + 飞书文档 | 分享画布链接 → 对方打开直接看到完整创意链路 | 所见即所得，不用整理文档 |
| 自己做过什么参数组合记不清 | 画布就是完整记录，节点+连线=操作历史 | 创意过程可回溯 |

## 一句话总结

旧版是「生成工具」——每次独立操作，做完就散了。

新版是「创意工作台」——所有操作在一个画布上完成，过程自动保存，结果可对比可复用。
