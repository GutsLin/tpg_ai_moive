# 成员独立 API Key — 按人统计 Token 消耗方案

## 背景

当前所有成员共用一把系统级 API Key 生成视频，ToAPIs 中转平台接口不返回单任务 Token 用量，导致无法按成员拆分消耗。ToAPIs 后台支持按 API Key 查看用量统计，因此为每个成员配置独立 Key 即可实现按人核算。

## 方案概述

给每个成员配置独立的 ToAPIs API Key，生成视频时优先使用成员个人 Key。系统全局 Key 保留作为兜底，管理员可一键切换两种模式。

| 模式 | 说明 | 适用场景 |
| --- | --- | --- |
| 全局共享（当前默认） | 所有成员使用系统统一 Key | 无需按人统计 |
| 成员独立 | 每人用自己的 Key，未配置则无法生成 | 需要按人统计 Token 消耗 |

## 改动点

### 后端

| 序号 | 改动 | 说明 |
| --- | --- | --- |
| 1 | 新增 `user_api_keys` 表 | 存储每个成员的加密 API Key |
| 2 | 新增 `api_key_mode` 配置项 | 全局/成员模式开关 |
| 3 | 修改视频生成流程 | 创建任务时按模式选用对应 Key |
| 4 | 修改任务轮询流程 | 轮询时按用户解析 Key，无个人 Key 回退全局 |
| 5 | 新增用户 Key 管理接口 | 管理员为成员设置/查看/删除 Key |
| 6 | 新增模式切换接口 | 管理员一键切换模式 |

### 前端

| 序号 | 改动 | 说明 |
| --- | --- | --- |
| 1 | 用户管理页新增「API Key」按钮 | 管理员为每个成员录入 Key |
| 2 | 系统配置页新增模式切换 | 全局/成员独立一键切换 |
| 3 | 视频生成页增加提示 | 成员独立模式下未配置 Key 时提示用户 |

### 安全

- 个人 Key 加密存储（AES-256-GCM），接口只返回脱敏值
- Key 不写入日志、不存入任务表
- 仅管理员可设置他人 Key

## 使用流程

1. 管理员在 ToAPIs 后台为每个成员创建独立 API Key
2. Narrix 用户管理页录入各成员的 Key
3. 系统配置页切换为「成员独立 Key」模式
4. 之后在 ToAPIs 后台按 Key 查看每人 Token 用量
