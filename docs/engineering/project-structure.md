# 项目结构说明

本阶段只整理文档、脚本、测试和配置文件，业务源码与生产部署路径保持不变。

```text
backend/src/       后端业务源码、迁移和 worker
frontend/src/      前端业务源码
deploy/            Docker Compose、环境模板、Nginx 和部署脚本
config/            脱敏配置示例
scripts/           诊断与本地运维脚本
tests/backend/     后端测试
tests/e2e/         前端 E2E 测试
docs/              分类项目文档
```
